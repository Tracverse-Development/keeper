# Known issues

- [ ] **DESK-NODE-INSTALL-001** — The "install a DKG node" path (`dkg::node::install`) is built but has not been run end to end: this Mac already has a node, and installing a second one was not done here. Prove it on a clean Mac or user account before release. (2026-11-25, Medium)
- [ ] **DESK-ERASE-001** — Erasure: forgetting writes a retraction (DKG writes are additive), so the old fact's triples remain in the node's working memory. A full "delete everything" (a GDPR-style erasure of the person's graph) needs the node's own deletion path for working-memory assets; not built yet. (2026-11-25, Medium)
- [ ] **DESK-SIGN-001** — The app is ad-hoc signed, not with a Developer ID, and not notarised. Other Macs will warn on first open, and the microphone permission is tied to this exact build. (2026-11-25, Medium)
- [ ] **DESK-SHARE-001** — Everything stays in Working Memory. Sharing chosen memories to SWM (another device of the same person) is not built. (2026-11-25, Low)
- [ ] **DESK-PORTS-001** — Windows, Linux and mobile: `platform/unsupported.rs` and no voice helper. The mobile app is planned as a companion that talks to the desktop's node. (2026-11-25, Low)
- [ ] **DESK-HERMES-001** — Hermes on this Mac has no model provider connected (`hermes model`), so choosing Hermes falls back to the built-in mind until it is. (2026-11-25, Low)
- [ ] **DESK-CODEX-001** — Codex is installed on this Mac but not signed in (`codex login`); the engine list says so and it is disabled until then. Its adapter is unit-tested on the documented event shapes, not yet live. (2026-11-25, Low)
- [ ] **DESK-GEMINI-001** — The Gemini CLI adapter (`gemini -p`) is written from the CLI's documented flags but untested (not installed here), and it reads plain text, so its tool calls are not recorded step by step. (2026-11-25, Low)
- [ ] **DESK-PHONE-TLS-001** — The phone link is plain HTTP on the local Wi-Fi: the token and the conversation cross the LAN unencrypted, and a phone browser will not allow its own microphone on http (keyboard dictation works). Next: a self-signed TLS certificate pinned through the QR code. (2026-11-25, Medium)
- [ ] **DESK-ACT-001** — "Let my assistant act on this computer" runs agent engines with their permission prompts off (Claude `bypassPermissions`, Codex `danger-full-access`, Gemini `--yolo`). The system prompt forbids destructive actions without an explicit ask, and every tool call is recorded on the DKG, but nothing enforces it beyond the engine itself (and Agent Blackbox where installed). Next: route agent tool calls through Blackbox's guard, and a spoken confirmation for risky steps. (2026-11-25, Medium)
