# Architecture

Keeper is a Tauri 2 app: a Rust core (`src-tauri/src/`), a React window (`src/`) and a small
Swift helper for the voice (`native/voice/`). Its memory is the person's own OriginTrail DKG V10
node: every fact, conversation, action and reminder is a Knowledge Asset in a private Context Graph,
and every recall is a bounded SPARQL query. There is no other database.

```
 person ──speech──▶ keeper-voice (on-device recogniser) ──▶ voice ──▶ window ──▶ assistant::turn
                                                                          │
                     ┌──────────── recall (SPARQL, working memory) ◀──────┤
 DKG node ◀──────────┤                                                    ├──▶ brain (Ollama │ Hermes │ Reflex)
 (127.0.0.1)         └──────────── remember (Knowledge Assets) ◀──────────┤
                                                                          └──▶ sdk (abilities in packs)
```

Dependency rule: modules use `kernel` freely. `memory → dkg`; `brain → memory (types), sdk (catalogue)`;
`sdk → memory, platform, pim, stage (panels, person_file), system (the startup disk, the load), focus (sessions), state, keepers (a mode's rules, for instant answers), brain (the engine catalogue; the clipboard's helper model), assistant (attach: material fences)`; `voice → platform`; `phone → assistant, state, sdk (the clipboard's words)`; `updater → state`; `setup → dkg, brain, keepers, platform`; `keepers → dkg, assistant, platform`; `hotkey → voice (through state)`; `assistant → memory, brain, sdk`; `backup → memory, keepers, brain (the engine catalogue), platform, state`.
`kernel` never imports a module. `platform` is the only place that names an OS tool (`structure.test.ts`).

`src-tauri/binaries/keeper-voice-<triple>`.

## Guards

- `scripts/proof.sh` (release gate): every memory test for real against this Mac's node, in a sub-graph. `scripts/bench/smoke.sh` (release gate): a test copy of the real app is sent real messages and every reply is checked. Both run from `scripts/release.sh` before a tag.
- `src/structure.test.ts`: this file lists every module that exists on disk (manifest), the kernel imports no
  module and only `platform/` runs OS tools (boundaries), no source file over 400 lines (size).
- `src/kernel/events.test.ts`: the window's event names equal the core's.
- `structure.test.ts` also keeps the core's and the character's catalogues equal: parts (ids, slots, effects, ranges), slots (ids, order, kind) and each species' slots.
- `src/character/parts/wearables-fit.test.ts`: every worn wearable is built for every species that offers its slot (and a made-up boxy, four-armed body) and measured: nothing sinks into the body, it sits close, sleeves only where there are limbs.
- `memory::queries` tests: every query is bounded, names a class, and never joins across assets (LES-001).
